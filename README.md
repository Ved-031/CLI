# Scaffoldy CLI 🚀

[![npm version](https://img.shields.io/npm/v/scaffoldy-cli?color=brightgreen)](https://www.npmjs.com/package/scaffoldy-cli)
[![License](https://img.shields.io/npm/l/scaffoldy-cli)](https://opensource.org/licenses/MIT)
[![Downloads](https://img.shields.io/npm/dt/scaffoldy-cli)](https://www.npmjs.com/package/scaffoldy-cli)

**Scaffoldy CLI** is a lightning-fast command-line tool to scaffold modern web applications with React, Next.js, and Express. It comes preconfigured with Tailwind CSS, Shadcn UI, Prisma, and other popular tools, so you can start coding immediately without worrying about setup.


## Features ✨

- Generate React, Next.js, or Express projects in seconds
- Built-in support for **Tailwind CSS**, **Shadcn UI**, and **Prisma**
- Ready-to-use, scalable folder structure
- Interactive CLI with easy-to-follow prompts
- Lightweight and fast

## Installation

Install Scaffoldy CLI globally using npm:

```bash
npm install -g scaffoldy-cli
```

Verify installation:

```bash
scaffoldy-cli --version
# or
npm run create-scaffold-app --version
```

## Quick Start Guide ⚡

### Step 1: Create a new project

```bash
npx create-scaffold-app
```

**Follow the interactive prompts**


### Step 2: Navigate to your project

```bash
cd my-new-project
```

### Step 3: Run development server

Follow the step specified by the CLI after creating successfull project.


## CLI Commands 🖥️

| Command                       | Description                                          |
| ----------------------------- | ---------------------------------------------------- |
| `npm run create-scaffold-app` | Starts the interactive CLI to scaffold a new project |
| `scaffoldy-cli --help`        | Shows CLI usage instructions                         |
| `scaffoldy-cli --version`     | Shows CLI version                                    |
